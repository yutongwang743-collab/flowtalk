# 趣魅 · 复古橙视觉重设计

日期: 2026-06-13 | 状态: 已批准

## 设计方向

**复古橙 × 手写体 × 平涂色块 × 手绘插画**

70 年代海报质感——陶砖深红打底，手写标题，纯色块卡片，粗线手绘装饰。像一家老咖啡馆的手绘菜单。

## 色彩系统

| 令牌 | 色值 | 用途 |
|------|------|------|
| 主色 陶砖 | `#A64B3A` | Hero 背景、主按钮、深色卡片 |
| 深色 深砖 | `#8B3A2A` | 文字强调、边框、hover 态 |
| 辅色 浅陶 | `#D4A090` | 中色卡片、标签、分割 |
| 底色 暖白 | `#FDF0EA` | 页面背景、浅色卡片、文字底色 |

不使用 Tailwind 颜色系统——所有颜色以 CSS 变量或内联 style 方式注入。

## 字体

| 层级 | 字体 | 风格 |
|------|------|------|
| H1/H2 标题 | 手写/圆体风格（如 ZCOOL KuaiLe 或类似） | 粗圆、有温度 |
| H3/正文 | Noto Sans SC | 清晰可读 |
| 按钮/标签 | 手写体 | 统一风格 |

## 卡片系统

- **平涂色块**：无边无影，纯色背景
- **三色交替**：暖白底 → 浅陶底 → 陶砖底，循环排列形成视觉节奏
- 不同模块用不同色深的色块：课程用暖白、练习用浅陶、社区用陶砖

## 装饰系统

- 粗线圆圈边框（`border: 2-3px dashed/solid`）
- 手绘小马线稿（emoji 🐴 放在圆圈内）
- 对话气泡 💬 散布
- 咖啡 ☕ / 书本 📖 / 铅笔 ✏️ 等小元素点缀
- 圆形几何色块作为背景纹理

## Hero 设计

- 陶砖红 `#A64B3A` 满铺背景
- 右上角装饰性同心圆（半透明暖白线）
- 左下角 🐴 大号水印
- 标题手写体白色
- 主按钮 暖白底 + 深砖字
- 次按钮 透明 + 暖白边框

## 导航

- 顶部固定，暖白半透明底
- 选中态：深砖下划线圆点
- Logo: 🐴 + "趣魅" 手写体
- 移动端底部栏：暖白底 + 陶砖选中色

## 页面布局

- 11 个页面保持现有路由不变
- 首页：Hero（陶砖）→ 名言（暖白）→ 课程卡片（三色交替网格）→ 场景入口（大色块）→ 社区（浅陶底）
- 课程详情：暖白底 + 五段式Tab（陶砖选中态）
- 练习：浅陶底 + 暖白输入区
- 登录/注册：陶砖左半屏 + 暖白右半

## 插画元素位置

- Hero 右上角：同心圆装饰
- Hero 左下角：🐴 大号水印
- 卡片内部：小图标圆圈包裹
- 空状态：🐴 线稿 + 波浪线文字

## 技术实现

- 所有视觉样式用 JSX `style={{}}` 内联
- globals.css 只保留字体加载和 prose-content 排版
- tailwind.config.ts 不扩展颜色（避免层叠冲突）
- 手写字体从 Google Fonts 加载
