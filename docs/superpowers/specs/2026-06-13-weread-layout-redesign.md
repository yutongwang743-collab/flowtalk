# 趣魅 · 微信读书风格页面重构

日期: 2026-06-13 | 状态: 待审批

## 设计目标

将趣魅页面结构从"手账风多层级装饰布局"改为**微信读书风格的内容驱动单列布局**：灰白底、白色卡片、克制留白、内容优先。保留暖色系品牌温度作为点缀。

## 布局骨架

### 去除
- LeftSidebar（桌面端左侧每日一句区域）
- Footer（底部版权区，合并到页面底部简版）
- Hero Banner（陶砖满铺大 Banner + 装饰圆 + emoji 水印）
- 所有装饰元素（dashed 圆框、emoji 水印、三色交替卡片）

### 保留改造
- TopNavbar → 微信读书风标题栏（品牌名 + 搜索框 + 通知铃铛）
- BottomTabBar → 底部 5 Tab（首页/学习/练习/社区/我的）

### 全局参数
- 页面底色: `#f5f5f5`
- 卡片底色: `#ffffff`
- 卡片间距: `8px`
- 内容区最大宽度: `640px`，居中
- 卡片圆角: `6px`
- 字体: 系统无衬线（PingFang SC / Noto Sans SC），移除大面积手写体
- 品牌色: `#8B3A2A`（深砖，仅用于点缀）

## 品牌色使用范围
- Tab/Category 选中态背景
- 编号数字色（`#D4A090` 浅陶）
- CTA 按钮
- 每日一句卡片底色（`#FDF0EA`）
- 文字链接色
- 图标区域渐变色

## 页面设计

### 1. 首页 `/`

**3 模块结构：**

| 序号 | 模块 | 数据源 | 布局 |
|------|------|--------|------|
| 1 | 按场景学习 | `categories` 配置 | 3×2 图标网格 |
| 2 | 每日一句 | `prisma.quote` | 暖色文字卡片 |
| 3 | 情景讨论 | `prisma.post` | Feed 列表 |

**场景网格卡片：**
- 白色背景 `#fafafa`，居中排列
- emoji 图标 24px + 场景名 10px/600 + 课程数 8px 浅陶色

**情景讨论卡片：**
- 用户头像（小马 emoji 圆形）+ 用户名 + 时间
- 正文 11px，行高 1.7
- 标签（小圆角灰底）
- 底部互动栏：❤️ 数字 + 💬 数字，浅灰色

### 2. 学习中心 `/lessons`

**结构：**
- 顶部标题栏（居中标题 + 左返回）
- 分类横滚 Tab（圆角药丸样式，选中态深砖背景白字）
- 课程计数
- 两列编号网格

**卡片规格：**
- 水平排列：编号 + emoji 图标 + 标题
- 小长方形，padding: 8px 10px，白色底 6px 圆角
- 编号: 13px/700 浅陶色
- 标题: 10px/600
- 两列网格: `grid-template-columns: 1fr 1fr; gap: 8px 10px`

### 3. 课程详情 `/lessons/[slug]`

**结构：**
- 顶部标题栏（返回 + 收藏星标）
- 分类标签 + 标题 h1 + 描述 + 元信息（章节数/学习人数/时长）
- 课程大纲（编号列表）
- 底部 CTA（深砖色横条：引导去练习）

### 4. 练习中心 `/practice`

**结构：**
- 顶部标题栏
- 说明文字
- 场景列表（白色卡片行，左侧 emoji + 标题/难度 + 右箭头）

### 5. 社区 `/community`

**结构：**
- 顶部标题栏
- 快速发帖输入框
- 帖子 Feed（与首页情景讨论模块复用）

### 6. 其他页面

- **练习详情 `/practice/[id]`**: 内联样式保持不变，底色改为 #f5f5f5
- **社区详情 `/community/[id]`**: 同上
- **登录 `/login`** 和 **注册 `/register`**: 简化为居中卡片式
- **个人中心 `/profile`**: 保持空状态，卡片式
- **收藏 `/favorites`**: 保持空状态，卡片式

## 导航变更

### 顶部栏（替代 TopNavbar）
- 左侧: 🐴 + "趣魅" 品牌名（保留手写体）
- 中间: 搜索框（圆角 14px，灰底，占位文字）
- 右侧: 通知铃铛
- 背景白底，底部细线分隔
- Sticky 定位

### 底部 Tab（替代 BottomTabBar）
- 5 项：首页 / 学习 / 练习 / 社区 / 我的
- 图标 + 文字
- 选中态: 深砖色 `#8B3A2A`
- 未选中: 灰色 `#bbb`
- 白底 + 顶部分隔线

### 导航映射调整
| 当前 | 改为 |
|------|------|
| TopNavbar 桌面端主导航 | 简化为标题栏（无导航链接） |
| LeftSidebar 每日一句 | 移入首页卡片 |
| Footer 底部链接 | 去除，底部 Tab 覆盖 |
| BottomTabBar 4 Tab | 扩展为 5 Tab |
