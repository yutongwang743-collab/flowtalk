# 趣魅 — 视觉系统设计规范

日期: 2026-06-13 | 状态: 已批准

## 概述

趣魅是一个沟通能力学习社区。视觉定位为**手账漫画风格**——像翻一本精致的手账本，安静有温度，萌趣不幼稚。

## 设计令牌

### 品牌色

| 令牌 | 色值 | 用途 |
|------|------|------|
| 森绿主色 | `#6B7B4E` | 按钮、链接、标题、选中态 |
| 草绿辅色 | `#8FA86A` | 卡片边框、次要文字 |
| 浅草边框 | `#C5D5AE` | 默认边框、分割线 |
| 淡草背景 | `#E8EFDE` | 页面底色、标签背景 |

### 点缀色

| 令牌 | 色值 | 用途 |
|------|------|------|
| 暖珊瑚 | `#E07B6C` / `#C45C4A` | 练习模块、强调元素、爱心 |
| 暖棕 | `#D4A76A` / `#8B6914` | 社区模块、暖色点缀 |
| 米白底 | `#FAFAF5` | 卡片背景、全局底色 |

### 字体

| 层级 | 字体 | 字重 | 大小 |
|------|------|------|------|
| H1 | Noto Serif SC | 700 | 28px |
| H2 | Noto Serif SC | 700 | 22px |
| H3 | Noto Sans SC | 700 | 18px |
| 正文 | Noto Sans SC | 400 | 14px / line-height 1.7 |
| 引用 | Noto Serif SC | 400 italic | 15px |
| 小字 | Noto Sans SC | 400 | 11-12px |

## 组件规范

### 卡片

- 边框: 2px solid 草绿辅色 `#8FA86A`
- 圆角: 12px (`rounded-xl`)
- 背景: 米白 `#FAFAF5`
- 无阴影 (`shadow-none`)
- 不同模块可用不同点缀色边框区分（练习=珊瑚, 社区=暖棕）

### 按钮

- 主按钮: 森绿背景 `#6B7B4E` + 白色文字 + 圆角 10px
- 次按钮: 白色背景 + 2px 草绿边框 + 森绿文字
- 幽灵按钮: 无背景无边框 + hover 淡草背景
- 圆角统一 rounded-xl

### 导航

- 桌面端: 顶部固定导航栏，白色半透明背景 + 毛玻璃效果
- 移动端: 底部固定 Tab 栏，白色背景 + 顶部边框
- 选中态: 淡草背景 + 森绿文字
- Logo: 🐴 小马 emoji + "趣魅" 宋体文字

### Hero

- 渐变背景: `#F0F5E8` → `#FAFAF5` → `#F5F0E8`
- 细线描边
- 右侧放置 🐴 吉祥物（半透明大图）
- 标题用宋体，正文用黑体

## 吉祥物

**名字**: 小趣  
**形象**: 一匹热爱沟通的小马 🐴  
**意义**: 马年吉祥物，象征自由表达、驰骋畅谈  
**变体**: 🐴 默认 · 🐎 奔跑 · 🦄 奇思妙想 · 🏇 加油

## 移动端适配

- 底部 Tab 导航（首页/学习/练习/收藏/社区/我的）
- 左侧名言区收起为抽屉（顶部汉堡菜单触发）
- 卡片全宽排列，单列布局
- 字体等比缩小，保持层级清晰
- Hero 吉祥物缩小至不遮挡标题

## 动画

- 名言滚动: CSS animation, hover 暂停
- 卡片 hover: 边框颜色加深 + 轻微 scale
- 按钮 hover: 背景色加深 100ms transition
- 页面进入: fade-in + slide-up 0.5s
